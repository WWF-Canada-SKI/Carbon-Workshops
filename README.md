# Carbon Workshops

A shared website and resource library for ecosystem carbon workshops. Each workshop and component has its own page, so you can share the relevant guide directly.

## Workshop collections

- [Blue Carbon — Eelgrass](Blue%20Carbon%20Workshops/): Background, Project Planning, Field Methods, Data Interpretation, and a Worked Example.
- [Green Carbon](Green%20Carbon%20Workshops/): Forests, Grasslands, and Wetlands, with field guides, calculators, worked examples, and shared resources.

## Website

This repository builds with Jekyll and deploys through the **Publish Workshop Website** GitHub Actions workflow. Find the deployed URL under **Settings → Pages** or in the latest successful deployment.

Each folder's `README.md` becomes its website homepage. Other Markdown guides become HTML pages, while images and downloadable resources remain beside the guides.

See [SITE_GUIDE.md](SITE_GUIDE.md) for editing, adding components, and moving changes between a personal fork and the work repository.
