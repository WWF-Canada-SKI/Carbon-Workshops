# Archived worked-example material

These files are kept for reference. They are **not** part of the current workshop.

| File | What it was | Why it is archived |
|---|---|---|
| `04_Data_Interpretation_Tsawwassen.md` | The original Part 4 walkthrough: six Tsawwassen cores (3 salt marsh, 3 eelgrass) taken from bagged samples to a stratified stock and a prior–data combination | The data are **constructed for teaching**, not field measurements. The walkthrough was built on the earlier pipeline (`04_Data_Interpretation/DataAnalysisWorkflow/advanced/`), which is no longer the participant workflow |
| `Eelgrass_Carbon_DigitalData_Example_Tsawwassen.xlsx` | The digital data sheet filled in with those constructed cores, in the original template | Superseded by the revised workbook (carbon type, slice checks, depth increments) and the Cowichan example in `04_Data_Interpretation/files/` |

The Tsawwassen team's **planning** story stays in [`../02_Project_Planning.md`](../02_Project_Planning.md),
labelled as constructed. The current analysis examples use openly published Cowichan cores
(Douglas et al. 2022, via Janousek et al. 2025). See [Part 4](../../04_Results/).
